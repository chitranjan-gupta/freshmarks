# Changelog

## [1.0.0] - 2024-04-01
### Added
- Initial release of FreshMarks extension for Chrome and Firefox.
- Listens for HTTP redirects (301, 302) and updates bookmarks with the new URL.
- Supports multiple bookmarks.

### Changed
- Updated `chrome/manifest.json` and `firefox/manifest.json` to version 1.0.0.
